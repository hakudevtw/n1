# モリタン ドリル

JLPT N1 に向けた単語・文法の**取り出し**練習アプリ。通勤中に片手・立ったまま使えることだけを目的にしている。

→ **https://hakudevtw.github.io/n1/**（ホーム画面に追加するとオフラインでも動く）

## なぜこの形なのか

見て覚えるのではなく、**思い出せずに詰まってから答えを見る**ほうが残る。だから全部クイズ形式で、解説は答えたあとにしか出ない。

漢字の意味は中国語話者には無料なので、弱点は**音**に寄る。だから主軸は「音を聞いて意味を選ぶ」──教科書を読むだけでは一生訓練されない方向。

## 中身（4 つのタブ）

| タブ | 中身 |
|---|---|
| 今日 | 到期の復習・新詞・長期記憶・連続日数。「開始」と「只複習 5 分鐘」。延遲測驗 |
| 歷程 | 近 12 週の熱度圖、長期記憶の折れ線、箱の分布、直近 30 日の量と正解率、延遲測驗、leech、教練の留言、同期紀錄。カードを開くと検査（箱・期日・lapses・最近 10 回の作答） |
| 素材 | 漢字ネットワーク／N2 文法 24 項目／読解（タイマー付き） |
| 設定 | 新詞の上限・朗読速度・表示、**同期**、優先詞、資料健康、已會匯入、診断、危險區 |

## 出題エンジン（間隔複習）

`js/srs.js` のスケジューラ（純関数）が全部決める。日付で解禁する仕組みも「連続 2 回で退場」も無い。

- カードごとに `{box, due, lapses, …}`。間隔は箱 0〜6 = `[0, 1, 3, 7, 14, 30, 60]` 日。答えると 1 つ上、間違えると箱 1（明日）。**箱 4 以上＝14 日以上の間隔で答えられた＝長期記憶**。
- 新カードは先に答えを見せ、同じ場で 2 回取り出させてから箱 1 へ。
- **到期の復習を先に片づける。残っていれば新詞は出ない。** 新詞は 1 日の上限（既定 20、5–50）まで、優先詞が先頭。「只複習 5 分鐘」は復習だけ（既定 20 題）。
- 出題型は箱で増える: 箱 0–2 = 音→意・漢字→読み／箱 3〜 = ＋意味→語・文中の語／箱 4〜 = ＋聞き取り→仮名入力。
- **延遲測驗**: 14 日以上前に答えた語（箱 3 以上）から 20 問、ヒントなし・答え合わせは最後。「本当に覚えたか」の指標。
- 「わからない」は間違いと同じ扱い（正解率の分母には入れない）。当てずっぽうで通れないようにするため。

### 通れなくなるのを防ぐ

「何度答えても通れない」を起こさないための仕組み（稽古の結果は `tools/audit-data.js`）。

- 同義・同音の語を選択肢に混ぜない（禁止／禁じる、準備／用意、同音語の意味）。選択肢の重複・空白を除き、正解が一つに決まらない題は作り直す。
- 一語多読（角＝かど／つの）はどちらの読みでも正解。TTS が別の読みをしないよう、仮名で読み上げる。
- 仮名入力は全角・半角・カタカナ・空白・ダッシュを揃え、長音（ー／う／お）の揺れを許す。
- 学習中のカードを 3 回外したら明日に回す（場が終わらなくなるのを防ぐ）。日本語の声が無い端末では「聴く」型を出さない。
- 練習中の「**這題怪怪的**」で題面を記録して中立にスキップ（成績に入れない）。その語ではその型を出さなくなる。「**我熟了**」で箱 5 へ。

## 同期（クリップボードだけ）

サーバは無い。毎日おわりに **設定 → 今日の同期包をコピー**（`n1.sync`、前回以降の増量）→ Claude に貼る。返ってきた `n1.coach` を **貼る → 預覽 → 確認** で套用（適用前に自動スナップショット、同じ包を 2 回貼っても重複しない）。`n1.backup` で全部のバックアップ／還原。JSON の定義は **[docs/SYNC.md](docs/SYNC.md)**。

保存データが壊れていても黙って初期化しない。警告を出して保存を止め、スナップショット（最新 3 件）やバックアップから戻せる。iPhone は「ホーム画面に追加」で開くこと（設定の「資料健康」に永続ストレージの状態が出る）。

## 毎日の更新

`js/data/words.js` の `window.DAYS` に日付ぶんを足すだけ。ビルド無し・依存無し。
更新したら `sw.js` の `CACHE` を上げると端末側も入れ替わる（新しい JS を足したら `ASSETS` にも）。

```
index.html          画面の骨
css/app.css         トークンのみで light / dark 両対応
js/srs.js           スケジューラ（純関数）
js/audit.js         詰まり防止（仮名の正規化・選択肢の検査）
js/sync.js          同期・バックアップ（純関数）
js/history.js       歷程の SVG 図（手刻み）
js/app.js           画面と出題
js/data/words.js    単語・文中選択・読解本文
js/data/grammar.js  N2 文法
sw.js               オフライン用
docs/SYNC.md        同期 JSON の定義
tools/              node tools/test-srs.js / test-sync.js / audit-data.js
```

## アイコン

`icons/source-artwork.png` から `python3 tools/make-icons.py` で全サイズを書き出す。
依存ライブラリは無し（PNG のデコード・リサイズ・エンコードを素で書いてある）。
通常用は寄せ気味、`icon-maskable-512.png` は Android の円形マスクの安全域に収まるよう余白を足してある。

学習計画そのものは別リポジトリ（`exam/n1`）で管理している。
